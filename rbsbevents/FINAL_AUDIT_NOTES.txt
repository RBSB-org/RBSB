EVENTWALE ADMIN PANEL - PATCH NOTES

This patch addresses a specific admin-panel gap found in admin.js:
- Content forms wrote events/venues/services/locations to Firebase, but the admin panel did not subscribe to those collections or render their table rows.
- The Analytics counters listened to events/services/venues, but the same listeners did not update the Manage tables or overview counts.

Changes in this build:
1. Live table rendering for /events, /venues, /services, and /locations.
2. Overview event and venue totals update from Firebase snapshots.
3. Analytics counts refresh for events, services, venues, and bookings; locations also have a live table listener.
4. Edit buttons populate the existing content form and save changes to the existing Firebase record.
5. Delete buttons remove a record after confirmation; Firebase rules must permit an authenticated admin to delete it.
6. Better console/toast diagnostics when a collection cannot be read.

Before testing:
- Deploy the contents of rbsb_work to the same hosting location as the existing website.
- Serve the site over HTTP/HTTPS (not by opening admin.html as a file:// URL), because Firebase module imports require a web server.
- In Firebase Realtime Database, confirm /admins/<signed-in-admin-uid> is the Boolean true.
- Confirm published database rules permit admin reads/writes for /events, /venues, /services, and /locations. The local FIREBASE_DATABASE_RULES.json file does not change published rules until you explicitly publish/deploy them.
- Hard refresh the admin page after deployment.

Manual verification checklist:
1. Sign in as an admin and open Manage Events. Add a test event; it should appear in the table after Firebase confirms the write.
2. Repeat for venues, services, and locations.
3. Edit one record and verify its existing database key remains the same.
4. Delete a test record and verify it disappears from the table and Firebase.
5. Open Analytics and verify the counters update. With Chart.js reachable, both charts should render; if not, check browser DevTools Console/Network for CDN or Firebase errors.

Limitations:
- This package has not been tested against the user's live Firebase project or hosting environment.
- The local rules file is only a reference; it does not automatically update Firebase Console.
- The public-facing site pages may require their own Firebase readers to show these records dynamically; this patch specifically fixes the admin tables and admin analytics counters.
